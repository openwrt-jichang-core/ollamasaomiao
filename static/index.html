01 主机地址

添加任意数量的 Ollama 服务地址，例如 http://192.168.1.10:11434。星标收藏常用地址，关闭开关可临时排除某个地址（不删除，也不参与扫描）。点击 🏷 可以给主机打标签（比如机房/账号分组），下方输入框按标签筛选。

粘贴含有多个地址的文本，会自动提取 ip:port（没写端口默认按 11434）。仅限你自己的内网/授权主机——非内网（非 10.x / 172.16-31.x / 192.168.x）地址会先弹出确认，不会静默加入。

          06 设置

          定时扫描

          开启后，每天固定时间自动跑一次全量扫描（只扫描已启用的主机），跑完会自动和上一次结果做对比，异常会通过下方启用的渠道推送。

          地址自动发现（从网页提取）

          定期访问一个网页（自己的域名或局域网地址都行），从返回内容里提取 ip:port（没写端口默认按 11434），自动加进主机列表。 适合"内网地址会变、通过网站中转上报当前地址"这种场景。
          如果目标域名开了 Cloudflare 防护：这里发的是普通 HTTP 请求，没法执行 JS，过不了 CF 的验证挑战页——这不是能靠改代码绕过的事。 建议去 Cloudflare 后台给本服务器出口IP或这个路径加一条"跳过安全检查"的规则，或者把这个页面放在一个不接入CF代理（DNS-only/灰色云朵）的子域名下。

          异常通知渠道

          可以同时启用多个渠道；发现「之前正常、这次变差」的主机/模型时会全部推送一遍。保存后可以点“发送测试通知”验证配置。

          历史趋势数据

          每次扫描完成后会自动追加一条汇总记录（不含主机地址等细节），用于下方的历史趋势图。为防止无限增长占满服务器磁盘，可设置保留天数和文件大小上限，超出的部分会自动从最旧的记录开始清理。

          只读分享链接

          开启后可以生成多个无需登录即可访问的只读链接（可各自命名、设置过期时间、单独吊销）。对方只能看到排行榜（主机地址会被替换成"主机1/主机2"这样的匿名编号），看不到真实主机地址、审计日志或任何管理功能。

          两步验证（TOTP）

          开启后登录时除了密码，还需要输入 Google Authenticator / Authy 等 App 生成的6位验证码，防止密码泄露后被直接登录。

          Prometheus 指标

          开启后可以用 Prometheus 抓取 /api/metrics（需要带上 token，作为 URL 参数 ?token= 或 Authorization: Bearer 头），只暴露主机数量/排行榜聚合数字等指标，不含主机地址。

          自定义语言性测试用例

          追加你自己的"语言性"测试题（纯文本规则判定，不执行任何代码，相对安全）。支持的规则：恰好N个汉字、某词出现次数、禁用词、编号列表条数、最大长度。会在下一次扫描/重测时生效。

          自定义核心测试用例 ⚠️ 高风险

          核心测试用例会把模型生成的代码拼上你写的 harness（断言脚本），在服务器沙箱子进程里真实执行。这等同于你自己在这台服务器上跑代码，请只在完全信任自己写的 harness 时使用。新增时需要重新输入登录密码确认，并会记录到审计日志。

          审计日志

          记录登录失败、设置变更、分享链接生成等管理操作。最多保留最近 1000 条。

          07 归档

          界面记录变多会显得很乱？点"归档并开始新一轮"，会把当前的主机地址+排行榜+扫描结果整体存一份快照（按日期命名），然后清空当前工作区重新开始——数据不会丢，之后在下面能看，加新主机时也会自动查一遍这些归档防止重复添加。

          对比两份归档

          选两份归档看差异：新增/消失的主机、状态变化、模型可用性变化——不用再自己一条条翻着比对。

          08 模型汇总（含归档）

          不管是当前工作区还是躺在归档里的记录，扫描到过的 主机+模型 都汇总在这一个列表，方便"恢复测试"——有些机器可能只是被你归档整理掉了，其实还在线。默认只显示当前工作区的记录，归档里的记录折叠隐藏，需要时再展开看。
